::: details 导入、草稿与扩展字段
在页面内创建、粘贴或修改的配置，点击“载入编辑器”不等于导出。浏览器允许临时存储时，尚未导出的完整草稿（包括凭据）会保存在当前标签页，刷新后可恢复；复制或下载后才标记为已导出。未经修改的文件导入仍以原文件为已保存基线。旧草稿若没有记录文件来源，会保守地保留为未导出状态。

服务商扩展字段留空表示继承全局 JSON `extra`；填写 `{}` 表示显式空覆盖，不会清除环境变量提供的扩展字段。导入会按运行时优先级处理平铺字段、`extra_` 别名和嵌套 `extra`。为保留有效值，必要时会将继承的字段显式展开到服务商的扩展字段中；这些显式值之后会覆盖全局设置。
:::
